# GeoDataGen

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Пользователи и разработчики GeoDataGen, которые настраивают сцены, запускают эксперименты gprMax и анализируют результаты.

## Product Purpose
Документация проекта объясняет запуск, устройство сцен, результаты и просмотр геометрии в ParaView. Пользователь скачивает репозиторий, устанавливает окружение и сохраняет каждый новый опыт в отдельную папку эксперимента.

## Capabilities and Constraints
Два генератора грунта: штатный Peplinski и модель полей CRIM/Archie. Управляемые сферические объекты, маршрут Tx/Rx, расчёт A-сканов и B-сканов. Антенна идеальная, без калибровки под конкретный прибор. Реальные данные GP8800 сняты в армированном бетоне и используются для наглядного сравнения формы отклика.

## Brand Commitments
Документация в стиле GitBook, иллюстрации непосредственно в статье, нейтральный русский язык. Содержание описывает интерфейсы, параметры и воспроизводимые рабочие процессы.

## Evidence on Hand
Сохранённые изображения и численные данные user_review/realism, разрезы трёх исходных сцен user_review/sections, разбор маршрута user_review/route. Изображения не заменяют доказательство точности моделирования реального прибора.

## Operating Context
Локальный статический HTML открывается без сборки и сети. Тот же документ предназначен для GitHub Pages. Все ссылки на файлы относительные. Команды выполняются из корня скачанного репозитория.
