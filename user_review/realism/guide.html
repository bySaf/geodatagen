Как работать с проектом

Полное руководство, все изображения и инструкции ParaView теперь собраны на главной странице.

Установить и открыть

git clone https://github.com/bySaf/geodatagen.git
cd geodatagen
bash scripts/setup.sh
source .venv/bin/activate
python geodatagen.py docs

Нужен Python 3.12 или 3.13. Поддерживаемый путь: macOS/Linux, в Windows — WSL2.

Создать отдельный эксперимент

python geodatagen.py init park-demo --mode custom_crim_archie
python geodatagen.py run park-demo --limit 1
python geodatagen.py plot park-demo
python geodatagen.py docs park-demo

Результаты — в experiments/park-demo/. Для полного маршрута повтори run без --limit 1. Все команды →

Настроить сцену

  • Добавить объекты и задать координаты.
  • Выбрать грунт, влажность и слои.
  • Изменить источник и маршрут.
  • Три большие сцены и случайная расстановка.

Открыть геометрию

python geodatagen.py export park-demo

В ParaView открой experiments/park-demo/scene/scene.vti, нажми Apply и создай Slice. Подробная инструкция с координатами разрезов →
