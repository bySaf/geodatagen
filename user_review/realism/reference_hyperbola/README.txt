РЕАЛЬНЫЙ ПРИМЕР С ЯВНЫМИ ГИПЕРБОЛАМИ

Бетон с арматурой, лабораторный образец II. Это реальные данные Proceq GP8800: ступенчатый SFCW-радар, 0,4–6 ГГц, шаг трасс 5 мм.

real_hyperbola.png — профиль 0–1,85 м / 0–6 нс и увеличение 0,85–1,35 м / 1,1–3,8 нс. Светлые и тёмные дуги — измеренные отклики. Теоретические гиперболы поверх них не нарисованы.
Для показа вычтена средняя трасса; контраст ограничен общим P99 в окне 0–6 нс. Шаг не увеличен до 5 см, сглаживания и дополнительного частотного фильтра нет. Это визуальный пример характерной формы, а не совпадение с моделью паркового грунта.

real_hyperbola.npz содержит все исходные 372 × 655 отсчётов, временную ось, координаты по номинальному шагу и отдельно обработанные для показа значения. Конец численной оси 1,855 м; CSV указывает длину 1,85 м. Ноль времени — начало экспорта прибора, не поверхность.

Источник: Mercedes Solla; данные SFCW предоставлены Screening Eagle Technologies.
