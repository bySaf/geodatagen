# GeoDataGen

GeoDataGen создаёт трёхмерный грунт, размещает объекты и рассчитывает георадарные сигналы в gprMax. Сцена и траектория задаются отдельными JSON. Все исходные настройки, координаты, геометрия и результаты одного запуска сохраняются в папке эксперимента.

## Примеры

[Парк, поле и дорога](examples/scenes.md) и [расчётные и реальные B-сканы](examples/scans.md).

Используются идеальный диполь и точечный приёмник. Проект не является цифровой копией конкретного прибора. Совпадение с реальными A-сканами требует данных об антенне и отдельной калибровки.
