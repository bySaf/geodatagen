# Сцена и объекты

Файл сцены задаёт грунт, цели, источник и вычислительную область. Файл траектории задаёт положения антенны. Один маршрут можно повторить над разными грунтами, а одну сцену — обследовать несколькими маршрутами.

```bash
mkdir -p configs
cp examples/scenes/park.json configs/my-park.json
cp examples/trajectories/snake.json configs/my-route.json
python geodatagen.py init my-park --scene configs/my-park.json --trajectory configs/my-route.json
```

## Основные поля

| Поле | Значение |
| --- | --- |
| `schema_version` | Версия формата: `2` |
| `generator` | `native_peplinski` или `custom_crim_archie` |
| `seed` | Начальное состояние генератора случайных чисел |
| `grid.domain` | Размеры области `[X, Y, Z]`, м |
| `grid.dx` | Шаг сетки материалов, м |
| `grid.solver_dx` | Шаг электромагнитного расчёта, м |
| `grid.surface_z` | Высота поверхности, м |
| `preset.layers` | Слои сверху вниз |
| `objects` | Явные сферические цели |
| `object_generation` | Правила случайной расстановки вместо `objects` |
| `source` | Импульс, частота, момент диполя, высота и разнос Tx/Rx |
| `simulation` | Фиксированная область или движущееся окно |
| `_provenance` | Обоснование численных параметров примера |

Длины задаются в метрах. Z растёт вверх. Глубина центра объекта равна `grid.surface_z - center_m[2]`. Размер ячейки — разрешение модели, а не точность измерения реального прибора.

## Выбор грунта

`native_peplinski` использует штатные `soil_peplinski` и `fractal_box` gprMax. Модель полей `custom_crim_archie` создаёт коррелированные пористость и водонасыщение, неровные границы и переводит их в электрические свойства через CRIM/Archie.

Выбор хранится в поле `generator`. Для отдельного опыта его можно переопределить:

```bash
python geodatagen.py init park-native --scene examples/scenes/park.json --trajectory examples/trajectories/snake.json --mode native_peplinski
```

Толщины `preset.layers` должны в сумме равняться `surface_z`. Минеральный слой задаёт `sand`, `clay`, `bulk_density`, `water_min`, `water_max`; фиксированный материал — `er` и `sigma`. Для модели полей нужна также проводимость поровой воды `custom.water_conductivity_s_m`.

## Точные координаты объектов

Фрагмент файла сцены:

```json
"objects": [
  {"type": "metal", "center_m": [3.0, 1.2, 0.45], "radius_m": 0.06},
  {"type": "air", "center_m": [4.0, 2.0, 0.50], "radius_m": 0.08}
]
```

`metal` — идеальный проводник PEC, `air` — воздушная полость, `dielectric` — тестовое диэлектрическое включение. Это сферы, не модели кабелей или труб. `objects: []` создаёт сцену без целей.

## Случайное размещение

`objects` и `object_generation` взаимоисключающие. Пример `examples/scenes/park-poisson.json` задаёт разнесённые случайные центры. Метод выбирается полем `method`:

- `uniform`: независимые равномерные кандидаты с проверками пересечений;
- `sobol`: последовательность Соболя для более равномерного покрытия;
- `poisson_disk`: случайные кандидаты с минимальным расстоянием между центрами.

`bounds_m` задаёт интервалы X и Y; `depth_m` в правилах — глубину центра, а не Z. `min_distance_m` дополнительно ограничивает расстояние между центрами для метода Пуассона; зазоры сфер всё равно проверяются по радиусам. Число объектов — `count` или `[минимум, максимум]`. Невозможная плотная расстановка заканчивается ошибкой, а не молчаливым уменьшением количества.

## Размер расчётной области

Полные примеры используют:

```json
"simulation": {"mode": "moving_window", "window_xy": [1.2, 1.2]}
```

Глобальный грунт создаётся один раз. Для каждой позиции рассчитывается локальное окно. Дальние отражатели за его границами не участвуют; окно может обрезать хвосты гипербол. Для проверки этого эффекта увеличьте окно или используйте `fixed` на посильной по памяти области. Размер PML — поглощающей границы — задаётся отдельно.
