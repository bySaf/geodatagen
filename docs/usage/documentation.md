# Сборка документации

Исходники находятся в `docs/`. Оглавление задаёт `SUMMARY.md`; изображения — в `docs/assets/`. Одни и те же Markdown-файлы используются для локальной документации и GitHub Pages.

```bash
python -m pip install -r requirements-docs.txt
python tools/build_docs.py
python tools/check_docs.py
```

Результат — `user_review/index.html` и отдельные страницы. Они открываются без сервера и интернета. Слева находятся поиск по названиям и оглавление; внизу каждой страницы — переходы к соседним темам.

Редактируйте Markdown и пересобирайте сайт. Ручные изменения сгенерированного HTML будут заменены. Проверка контролирует локальные ссылки, изображения и якоря разделов. GitHub Actions повторяет сборку перед публикацией.

Файлы `SUMMARY.md` и `.gitbook.yaml` также позволяют импортировать исходники в GitBook, если это потребуется. Для обычного использования проекта отдельный сервис не нужен.
